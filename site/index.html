    Why I built Appy

    I built Appy for my own internship search. Applying wasn't the hard part. Keeping track was: which roles I'd already sent, which email belonged to which application, which deadline was next.

    So the rules are strict. It checks the whole tracker before every application, so it never applies to the same role twice. It records a submission only after the employer's receipt arrives. When a form asks something my profile doesn't answer, it stops and asks.

    It runs on your machine, with your own agent and accounts. There is no server to sign up for, and nothing comes to me.

    It's MIT licensed and still early. If setup stops you somewhere, open an issue and tell me where. That's the most useful thing you can send.

    Cole GodfreyAuthor of Appy

    Common questions

    • Only if you say so. Your prompt sets the scope: a shortlist only, stop before each submit, or submit up to a number you name. Even then it uses only facts you wrote down.

    • Appy is free and MIT licensed. Your agent plan, optional TheirStack searches and Google Cloud for the email monitor may cost money; you set those limits.

    • A local agent that can drive Chrome and use Gmail and Notion. The guide uses ChatGPT's local work mode with Chrome; the optional email monitor uses the Codex CLI.

    • Your profile, resume and tracker exports stay in Git-ignored files on your machine. Your agent's provider and the services you connect still process what you send them.

    • It checks your complete tracker first, matching cleaned employer links and the company, title and term. A renamed role with a new link can still need a look.

    • Discovery targets summer internships in software, AI and data, quant, hardware and product. The application rules work for any search; other roles need new filters.

    • The public SimplifyJobs internship list, plus Greenhouse and Ashby boards when your agent runs full discovery. TheirStack is optional and paid.
